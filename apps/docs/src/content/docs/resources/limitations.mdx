Profanity Kit is a profanity detection toolkit, not a complete content
moderation system. The current MVP intentionally does not provide:

- phrase matching;
- substring matching;
- aggressive leetspeak expansion;
- contextual moderation; or
- mutable global dictionaries.

Create a detector with the configuration you need and apply human and
product-specific moderation policy around its results.
